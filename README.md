# ALWAN SPORT – Live

صفحة ويب لعرض القنوات (HLS) مع أماكن للإعلانات.

## الملفات
- `index.html` — الصفحة والمشغّل
- `ads.js` — إعدادات الإعلانات (الملف الوحيد الذي تعدّله للإعلانات)
- `ads/` — ضع هنا صور البانرات (مثل `banner1.jpg`)
- `.nojekyll` — يمنع GitHub Pages من معالجة الملفات

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على GitHub.
2. ارفع كل محتويات هذا المجلد (مع الملف المخفي `.nojekyll`).
3. من **Settings → Pages**: اختر Branch `main` والمجلد `/ (root)` ثم Save.
4. بعد دقائق يعمل الموقع على `https://USERNAME.github.io/REPO/`.

## ملاحظة عن `/proxy`
GitHub Pages استضافة ثابتة ولا تدعم المسار `/proxy`. القنوات التي روابطها تبدأ بـ `/proxy?url=` لن تعمل عليه،
وستعمل فقط القنوات ذات الروابط المباشرة التي يسمح مصدرها بالتشغيل من موقع آخر (CORS). ولأن GitHub Pages يعمل بـ https،
فروابط `http://` المباشرة تُحجب.
